## Reading these results honestly

- Top Recall@1 is 1.000, attained by: `fed_delete`, `fed_both`, `edr`, `dtw`, `erp`.
- Several methods tie at the top, so this regime does NOT separate them. A tie is not a win for FED; drawing a ranking between tied methods here would be unsupported.
- `fed_insert` abstained on every query (16/16). Its score of 0 is a TOTAL ABSTENTION, not a measured failure to rank.
- `fed_both` 1.000 vs raw `frechet` 0.115 on identical inputs. This is the mechanism the edit objective is designed for.
- No method strictly beat `fed_both` in this regime.

- No confidence intervals are reported. The query count here is a pilot and the units are not independent enough to support them.
- Per-query records for all 28 queries are in `per_query.json`.

## What this run does NOT establish

- Nothing about real GPS traces, GeoLife, T-Drive, or any measured data.
- Nothing about natural route recovery: that needs evidence level C,
  which requires independently annotated repeated trips and is BLOCKED.
- No latency or deployment claim; see `docs/performance.md` for timings.
